# RSIFlow Task components

This directory contains the adapted Task-agent runtime, reusable components,
candidate-generation templates, and validation utilities used by RSIFlow skill
evolution. It is shared by the 4B and 8B entry points.

These are adapted third-party components, not an independent RSIFlow method
release. Their original source and pinned revision are recorded in the
[third-party notices](../../../THIRD_PARTY_NOTICES.md).
